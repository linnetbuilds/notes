    Carrusel: 2026-10-29

    Las reglas que siguen mis agentes de IA. Cada una existe porque antes algo salió mal.

    1. Trae el registro original. Un resumen puede dejar fuera el contexto o equivocarse en un número. Antes de citar un número, una fecha o una cita textual, el agente busca el registro original. Ver R03.
    2. Primero la respuesta. Nada de felicitar la pregunta ni de narrar el método.
    3. Se admite el error una sola vez. Una frase corta y luego el valor correcto.
    4. Cada borrador, a la mitad. Los borradores que cumplían todas las demás reglas igual salían demasiado largos.
    5. Palabras prohibidas, revisadas al guardar. Un hook revisa cada archivo en el momento en que se guarda.
    6. Si hay duda, no se escribe. Coincidencia exacta: se escribe. Aproximada: me espera a mí. Ninguna: no se escribe.

    Listas para pegar, en inglés y en español, con el hook de la regla 5: resources/agent-rules.

    Costo: las reglas y el hook son archivos de texto plano, $0. Necesitan una herramienta de programación con IA; lo mínimo es Claude Pro, $20/mes (precios a oct 2026).
