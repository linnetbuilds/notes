# Linnet Builds: build notes

The notes behind each video from [@linnetbuilds](https://github.com/linnetbuilds): what the
tool does, what was measured on camera, and what it costs to reproduce.

Notas de cada video: qué hace la herramienta, qué se midió y cuánto cuesta. Los videos con
voz en español tienen su nota también en español.

**Monthly letter / Carta mensual:** what I built, what broke, what it cost.
[Letter (EN)](https://linnet-builds.kit.com/e0a423b289) | [Carta (ES)](https://linnet-builds.kit.com/da180bb515).
Everything here stays free, no email needed. / Todo lo de aquí sigue gratis, sin correo.

## Ground rules

- **Demo data on screen; the tools are real.**
- **Numbers are measured, not estimated.** If a video says "minutes later", the note says
  how many minutes on which run.
- **Costs are dated.** Prices change; each note says when its prices were checked. The
  computer, phone and internet connection are not counted.
